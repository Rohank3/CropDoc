# CropDoc 🌾🔬

**CropDoc** is an intelligent agricultural advisory and crop disease detection Progressive Web Application (PWA). It empowers farmers to rapidly detect plant diseases from leaf photographs, receive actionable organic and chemical remediation strategies, and monitor real-time weather and agro-climatic conditions directly from their smartphones.

## Key Features
- **Computer Vision Diagnostics**: Instant identification of crop diseases using deep learning models trained on agricultural pathology datasets (e.g. PlantVillage 38-class pathology).
- **Curated Remediation & Advisory**: Organic, biological, and chemical treatment guidelines with preventive measures.
- **Agro-Meteorological Forecasts**: Real-time hyper-local weather alerts, humidity, rain probability, and soil conditions to prevent fungal and bacterial outbreaks.
- **Progressive Web App (PWA)**: Mobile-optimized, offline-resilient, and installable on both Android and iOS devices.
- **Zero Mock / Genuine Pipelines**: Real models, live meteorological telemetry, and verified botanical knowledge graphs.
